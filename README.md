# Trivial Simulator

**Trivial Simulator** is a mobile application designed to assist citizens in identifying energy efficiency measures, enabling them to reduce energy costs and consumption in private homes.

## Features

- **User-Friendly Interface**: Accessible for authenticated users, with intuitive navigation and design.
- **AI-Powered Object Recognition**: Utilizing a pre-trained TensorFlow model, users can upload or capture images via the app to identify objects and receive tailored energy efficiency recommendations.
- **Cross-Platform Availability**: Published on the [Google Play Store](https://play.google.com/store/apps/details?id=com.brunohikaru.TrivialSimulator&pcampaignid=web_share) and [Apple App Store](https://apps.apple.com/pt/app/trivial-simulator/id6504252914?platform=iphone).

## Technologies Used

- **Frontend**: Developed using JavaScript with React Native and Expo to ensure a seamless and dynamic user experience.
- **Backend**: Firebase was employed for database management and backend services.
- **Artificial Intelligence**: Implemented with TensorFlow for object recognition.

## Development Process

1. **Mockups**: Designed mockups for both authenticated and unauthenticated user views.
2. **Implementation**: Built the app using modern JavaScript frameworks and tools like React Native and Expo.
3. **AI Integration**: Integrated object recognition capabilities via a pre-trained TensorFlow model.
4. **Publishing**: Successfully deployed the application to both the App Store and Play Store.

## Achievements

- **Innovative Use of AI**: Received positive feedback for the integration of AI-powered object recognition.
- **Client & Tester Praise**: Lauded for its intuitive interface and practicality in promoting energy efficiency initiatives.
- **First Mobile App**: Marked a milestone as the company's inaugural mobile application, setting the foundation for future technological advancements.
